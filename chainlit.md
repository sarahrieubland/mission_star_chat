# Mission STAR chat! 🤖✨

Ce chatbot est un proof-of-concept pour aider les utilisateurs à générer la description d'une mission en format STAR.

## Comment ca marche

Ce chatbot vous permet de :

1. **Poser une question** – Saisissez votre question dans la zone de chat à gauche
2. **Obtenir une réponse de l’IA** – L’IA génère une réponse à l’aide de GPT-4o-mini d’OpenAI
3. **Modifier et affiner** – La réponse apparaît sur le côté droit, où vous pouvez la modifier
4. **Enregistrer les changements** – Cliquez sur « Save Changes » pour sauvegarder vos propres modifications sur le texte STAR

## Fonctionnalités

- 💬 **Interface de chat** – IA conversationnelle sur le côté gauche
- ✏️ **Zone de texte modifiable** – Modifiez les réponses de l’IA sur le côté droit
- 💾 **Vue persistante** – Le texte modifiable reste visible pendant que vous continuez à discuter
- 🎨 **Écran divisé** – Mise en page claire avec le chat et l’éditeur côte à côte


## Pour commencer

Il vous suffit de taper votre question ci-dessous et de regarder la magie opérer !
La réponse générée par l’IA apparaîtra dans le panneau modifiable à droite, prête à être affinée et améliorée.
